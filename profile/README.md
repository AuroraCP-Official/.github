AuroraCP is a hosting control panel for secure server administration, straightforward account management, and affordable licensing. It is developed by Aurora Dragon Studio.

> **Status:** AuroraCP is in active development and is not yet released. Features listed below are planned and will be confirmed through testing.

## Features

- **Hosting**: accounts, websites, packages, and domains
- **Web and PHP**: web server configuration, PHP versions, and execution management
- **Security**: SSL certificates, account isolation, and secure administration
- **Databases**: provisioning and user management
- **Email and DNS**: mailboxes, DNS records, nameservers, and routing
- **Resellers**: delegated account management and hosting packages
