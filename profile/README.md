## ✦ What We're Building

| 🌐 Hosting & Domains | ⚡ Web & PHP |
|:---|:---|
| Hosting accounts, websites, packages, and domains | Web server configuration, PHP versions, and execution management |

| 🛡️ Security & SSL | 🗄️ Databases |
|:---|:---|
| Certificates, account isolation, and secure administration | Database provisioning and user management |

| ✉️ Email & DNS | 👥 Reseller Hosting |
|:---|:---|
| Mailboxes, DNS records, nameservers, and routing | Delegated account management and hosting packages |

> These are planned product capabilities. Availability will be confirmed through development and testing.
