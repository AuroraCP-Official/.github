## Overview

AuroraCP is a Linux hosting control panel being developed for hosting providers, system administrators, and businesses that need reliable server management without excessive licensing costs.

The project focuses on providing a unified environment for managing hosting accounts, websites, domains, email, databases, and essential server services.

Our priorities are straightforward:

- Reliable provisioning and account management.
- Secure isolation between hosting customers.
- Clear, consistent server administration.
- Predictable installation and update procedures.
- Affordable, transparent commercial licensing.

AuroraCP is being designed as an independent hosting platform, not a modification of cPanel or Plesk.

## Platform Architecture

The planned platform is organized around several core systems.

| Component | Responsibility |
|:---|:---|
| Hosting Management | Accounts, packages, domains, and resource allocation |
| Web Services | Web server configuration, PHP management, and virtual hosts |
| DNS | DNS zones, records, nameservers, and service integration |
| Email | Mailboxes, domain routing, and mail service administration |
| Databases | Database provisioning, users, and permissions |
| Security | Account isolation, SSL/TLS, access controls, and auditing |
| Reseller Management | Delegated administration and hosting packages |
| Backup & Recovery | Backup scheduling, restoration, and recovery procedures |
| Licensing | License activation, validation, and entitlement management |
| Installer & Updates | Deployment, configuration, upgrades, and maintenance |

These components represent the intended platform architecture. Individual capabilities will be confirmed as they are implemented and tested.

## Current Development

**Status: Active development and architecture validation**

AuroraCP has an existing development foundation. Current work is focused on researching and validating the operating-system and service integrations required for a reliable hosting platform.

Research areas include:

- Linux hosting account provisioning and filesystem permissions.
- Apache virtual-host configuration and PHP execution.
- DNS provisioning and domain lifecycle management.
- Email infrastructure and mailbox administration.
- Hosting packages, permissions, and reseller authorization.
- Service configuration, security, and recovery behavior.

This work will inform AuroraCP's independent provisioning engine and installation process.
